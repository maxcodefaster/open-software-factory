{{ if include "factory.managedIngressTLS" . -}}
This installation owns its HTTPS CA and renews Ingress leaf certificates automatically.
Native workloads receive only the public CA. Browsers and other clients must trust
that CA separately; a successful Helm install does not enroll client trust.

Using the same authenticated Kubernetes context as this Helm installation, export
only the public root and inspect its SHA-256 fingerprint:

  kubectl --context YOUR_SELECTED_CONTEXT --namespace {{ .Release.Namespace | quote }} get secret {{ printf "%s-ingress-ca" (include "factory.name" .) | quote }} -o jsonpath='{.data.ca\.crt}' | base64 --decode > factory-ca.pem
  openssl x509 -in factory-ca.pem -noout -fingerprint -sha256 -dates

Verify the fingerprint with the installation administrator before enrolling the
public root in client or enterprise trust policy. Never export signing keys or
disable certificate or hostname verification. Root replacement requires a planned
trust transition before the ten-year CA expires.
